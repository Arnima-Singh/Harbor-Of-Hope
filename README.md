
# Harbor Of Hope 🐾

A community-powered stray animal rescue and adoption platform built to connect people, volunteers, and rescue teams to help animals in need.

## About the Project

Harbor Of Hope is a web application that allows users to report stray animals requiring assistance. Volunteers can register, log in, and accept rescue tasks, while the rescue team manages reports and tracks rescue progress.

## Features

- Animal rescue report submission
- Animal photo uploads
- Volunteer registration and login
- Volunteer dashboard
- Rescue task acceptance
- Team login and dashboard
- Rescue status tracking
- Volunteer assignment management

- `app/` - Flask application

- `app/templates/` - HTML templates
- `app/static/` - CSS and static files
- `database.py` - Database configuration
- `run.py` - Application entry point

## Installation and Setup

1. Clone the repository:

   `git clone https://github.com/Arnima-Singh/Harbor-Of-Hope.git`

2. Open the project folder.

3. Create a virtual environment:

   `python -m venv .venv`

4. Activate it on Windows:

   `.venv\Scripts\activate`

5. Install dependencies:

   `pip install -r requirements.txt`

6. Configure the required environment variables in `.env`.

7. Run the application:

   `python run.py`

8. Open `http://127.0.0.1:5000` in your browser.
